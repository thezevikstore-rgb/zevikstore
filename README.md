# Zevik Store (@the_zevikstore)
React + Vite + Tailwind D2C storefront.
## Run
npm install && npm run dev
## Build
npm run build
## Setup
- Put your logo at `public/zevik-logo.png` (SVG fallback is automatic).
- Set `FORMSPREE_ENDPOINT` in `src/App.jsx`.
- Seller portal: footer "Seller Login" → thezevikstore@gmail.com + PIN 2026 (client-side only; not real security — use a backend for production).
